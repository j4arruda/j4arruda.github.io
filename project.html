My Computer Science Projects

Welcome to my projects page, this is a page with a couple of my previous projects in Computer Science. I have listed two projects from my previous class expiernece and one of my own personal projects. The last projected listed is the start up idea for this classes final project.

Past Projects

  • Python Compiler

    Class project

    I built a Python interpreter that converts encoded strings into arithmetic expressions and evaluates them. The project uses lexical analysis, recursive-descent parsing, and abstract syntax trees (ASTs) to process input and represent mathematical operations. Object-oriented design keeps the code organized and easy to extend.

  • BSU Eats

    Class Project

    Worked with a six-person team to develop a food-ordering application using Java and IntelliJ IDEA. My contributions included customer ordering and payment workflows, driver assignment and payouts, and database functionality for user accounts, orders, and transactions. I also participated in testing and debugging to help ensure the application worked correctly.

  • NFL Notebook

    Personal Project

    Developing a Python tool to explore historical NFL data and betting trends using nflreadpy, pandas, and Matplotlib. The project analyzes how often underdogs cover the point spread and visualizes results across seasons. I’m also building interactive features that let users explore specific weeks and spread thresholds, with a long-term goal of adding game outcome predictions
